### 核实的 SDK 契约与边界

- 安装版本生成的 Remote 声明为 discoverModels(settingsNs, request, signal?)，返回 RemoteResult<LlmDiscoveredModel[]>。
- 现有提供商传 provider，同时从当前 profile 带 baseURL/api；pi-ai 的 Host 只自动补已存储 headers/key，并不替客户端补 endpoint/protocol。
- Client 不请求明文密钥，也不把 apiKey 传给本轮查询；已存储凭据由宿主处理。
- pi-ai 内置已知路由读 SDK 内置目录，不联网。自定义目录仅支持 openai-completions / openai-responses 的 GET baseURL/models。
- Anthropic 自定义协议不支持该 SDK 的目录列举；未注册 discovery 的 DeepSeek 命名空间会拒绝。界面显示明确原因，不把当前配置或猜测 ID 冒充新查询。
- 目录不等于账号权限/连通性，不声称所有提供商都能动态列出模型，也未切换用户的协议。
