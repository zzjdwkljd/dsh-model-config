## 实际修复

- 接口信息随提供商详情自然撑开；取消事实卡片自身的滚动和高度截断。只有模型列表独立滚动，模型列标题留在列表上方；窄屏适当提高列表可用高度，必要时滚动外层详情区域。
- 已有提供商「查看更多模型」沿用 Host 的 `llm.discoverModels`：展示查询来源和限制，搜索、逐项/当前结果全选、已选数量；已配置项不可再选，未选择时无法提交。「添加所选模型」复用原来的 revision-checked settings 写入，只向该提供商的 `models` 增量合并，保留旧模型元数据；成功关闭目录并提示数量，失败/冲突留在目录中并允许重试。只读或不可编辑提供商仅能浏览。
- 新增提供商将模型表单整理成独立滚动的紧凑多行编辑器：桌面端只有一次列标题并固定在编辑器顶部，窄屏缩为两列输入并保留可辨识的逐行控件。保留模型 ID、名称、识图、思考、增删以及已有校验。
- 「获取可用模型」在无地址/非法地址时仍可点击，会聚焦地址并给出原因；查询中有明确状态，认证拒绝、无目录协议、空结果、网络错误都给出真实原因。查到候选后进入可搜索、可勾选的选择步骤；已在草稿的模型不可重复选；选择只加入本地草稿，须再按「创建」才提交配置。接口或密钥编辑/关闭时使旧请求失效。
- 原有导入导出、测试、增删提供商及配置接口仍受基线约束；没有改动真实配置、读取真实密钥或向真实供应商发测试请求。
